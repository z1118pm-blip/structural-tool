使用说明 · 假设与计算方法

一、工具定位

本工具是力学概念自检工具，用于帮助结构工程师快速验证对平面刚架受力性能的直觉判断。它不是工程设计或规范校核工具，计算结果的精度、荷载组合、稳定验算、抗震设计等内容均不适用于实际工程。默认的混凝土强度等级（C30）与截面尺寸仅用于提供量级参考，不作为设计依据。

二、计算模型与基本假设

  • 结构模型：平面刚架，参数化拓扑 —— 1~3 跨 × 1~3 层，可选右侧悬挑。柱列数 = 跨数 + 1；跨内梁数 = 跨数 × 层数；悬挑梁数 = 层数（开启悬挑时）。
  • 材料：均质、各向同性、线弹性。混凝土弹性模量 E = 3.0×10⁷ kN/m²（C30 规范值）。
  • 变形：小变形、小应变。不考虑几何非线性（不做 P-Δ 分析）。
  • 单元：平面梁单元，每节点 3 个自由度（水平、竖向、转角）。
  • 忽略：剪切变形、扭转变形、材料非线性、节点域变形、施工阶段效应、温度作用、收缩徐变、钢筋与混凝土滑移。

三、截面与刚度

  • 柱截面：bc × hc（出平面 × 平面内），Ic = bc·hc³/12，Ac = bc·hc。
  • 梁截面：bb × hb（水平 × 竖向），Ib = bb·hb³/12，Ab = bb·hb。
  • 中柱刚度比 r：中柱的 EI 与 EA 均为边柱的 r 倍。用于演示"柱刚度差异如何影响水平力分配"，界面保持简洁不展开为多组截面参数。
  • 截面按矩形实心计算，不考虑楼板共同工作、钢筋（纵筋与箍筋）等实际构造。

四、边界条件

柱脚（βf）

  • 平动（水平、竖向）始终约束。
  • 转动：βf = 1 时完全固定；βf = 0 时完全铰接；0 < βf < 1 时按弹性转动弹簧处理。
  • 弹簧刚度采用启发式公式 k_θ = (4EI_c/h₁)·β_f/(1−β_f)，使 βf 在 0.5 附近时弹簧刚度量级与柱自身转动刚度相近。它不是从节点平衡精确推导的弹簧刚度，只用于演示"从铰接到固定的连续过渡"。
  • 绘制柱脚符号：βf ≥ 0.99 画固定支座，βf ≤ 0.01 画铰接，中间画弹簧符号。

梁端（βj）

  • 通过修正梁单元局部刚度矩阵实现半刚接。
  • 采用标准半刚接梁单元模型，引入端部柔度参数 α = (1−β_j)/(4β_j)，对以下四项进行修正：
    项修正后
    横向刚度 kvv12EI/L³ · 1/(1+6α)
    耦合项 kvθ6EI/L² · (1+2α)/(1+8α+12α²)
    转动自项 kθθ4EI/L · (1+3α)/(1+8α+12α²)
    转动互项 kθθ'2EI/L · 1/(1+8α+12α²)
    固端弯矩wL²/12 · (1+6α)/(1+8α+12α²)
  • βj = 1（α = 0）退化为标准刚接梁单元；βj = 0（α → ∞）退化为两端铰接。

五、荷载

  • 梁均布荷载 q₁、q₂、q₃：分别作用于一层、二层、三层跨内梁。代码内部以局部坐标 w = −q 输入。
  • 悬挑均布荷载 qc1、qc2、qc3：作用于右侧各层悬挑梁，长度 Lc。悬挑梁为右柱节点伸出的标准刚接单元，不参与 βj 半刚接修正。
  • 水平力 H₁、H₂、H₃：两种施加方式
    • 仅左柱：全部施加于左柱顶节点，模拟风压从左侧来。
    • D 值法：按各柱侧移刚度分配。同层各柱端部约束相同，柱侧移刚度 ∝ EIc；内柱 EIc = r·边柱 EIc，边柱取 1、内柱取 r，归一化后分配。模拟地震作用按刚度分配。
  • 所有荷载为静力荷载，不考虑动力放大、偶然偏心、荷载组合系数。

六、求解方法

  • 采用矩阵位移法（直接刚度法）：组装整体刚度矩阵 K，组装等效节点荷载向量 F，施加边界条件后高斯消元求解 K·U = F。
  • 高斯消元使用部分主元法；对角元 < 1e-14 时判定为奇异并提示。
  • 反力由 R = K_struct·U − F 计算（K_struct 不含弹簧贡献）。对于弹性柱脚，代码里从 K·U 中扣除弹簧力 kθ·θ 后得到弹簧反力矩。

七、内力符号约定

  • 轴力 N：拉为正，压为负。
  • 剪力 V：与单元局部坐标一致，V(x) = dM/dx = f₁ + w·x。
  • 弯矩 M：M(x) = −f₂ + f₁·x + w·x²/2。弯矩图绘于受拉侧。
  • 内力图正方向与单元局部坐标的 y 轴一致（柱竖向、梁横向）。

八、已知近似与局限

以下几点是模型的简化，使用时需注意。用于教学演示足够，但不能作为设计依据。
  1. βf 弹簧刚度为启发式，不是严格推导的弹簧刚度。主要用于演示从铰接到固定的趋势，不能与真实转动弹簧刚度值对应。
  2. βj 修正的梁单元是标准半刚接模型，但对多层多跨刚架，节点处柱的转动约束没有单独建模（即梁端的半刚接在节点处自动与柱刚接），这会影响含半刚接节点刚架的整体刚度。
  3. D 值法分配用的是端点转动弹簧约束下单柱的侧移刚度系数（见 colKeff），不是规范的 D 值法 αc 表法。两者在「两端完全固接 / 完全铰接」的极端情况给出一致结果，中间过渡段不同。此外：
    • 柱脚 βf 是真正的柱脚转动弹簧，可直接作为下端点弹簧；
    • 梁端 βj 描述的是梁端半刚接，把它直接当作柱顶上端转动弹簧是近似 —— 真实节点处柱顶约束由梁的抗弯刚度决定；
    • 同层三柱端部约束未逐柱区分（当前取相同约束），梁的弯曲变形对柱顶约束的影响未单独建模。
  4. 无二阶效应：不做 P-Δ 分析，不放大侧移和弯矩。
  5. 无节点域：节点处按纯刚接或纯铰接处理，未考虑节点域剪切变形。
  6. 悬挑梁简化：悬挑梁按标准刚接单元处理，不参与 βj 半刚接修正；悬挑端为自由端，未建模实际边梁的弹性约束。
  7. 每根杆件一个单元：对于只有均布荷载的情况已足够精确，但对有多个集中力或复杂荷载的杆件精度有限。
  8. 无剪切变形：按 Euler-Bernoulli 梁理论，忽略 Timoshenko 梁的剪切效应。
  9. 无材料非线性：不考虑混凝土开裂、钢筋屈服等实际非线性效应。
  10. 线弹性范围：计算结果可用于叠加，但不适用于承载能力极限状态验算。
  11. 规范背景：默认采用中国现行规范体系（GB 50010、GB 50011 等），但不做规范校核，仅作为量级参考。

九、力学概念自检建议

  • 框架作用：把 βj 从 1 拖到 0，观察中柱上下轴力差从不为 0 变为 0，验证"梁对柱的约束如何影响竖向荷载传递"。
  • 水平力分配：切换「仅左柱」与「D 值法」，观察柱脚 Rx 的差别；把 r 调到 2 或 4，对比两种模式下柱脚反力的差异。
  • 节点刚度的影响：把 βf 从 1 拖到 0，观察侧移刚度 K 和最大层间位移角如何变化。
  • 弯矩重分布：把 βj 从 1 拖到 0，观察梁端弯矩如何消失、跨中弯矩如何增大。
  • 支座约束的影响：把 βf 从 1 拖到 0.5 再拖到 0，观察柱脚反力矩从最大值降到 0 的过程。
  • 悬挑引起的偏心弯矩：把 qc1、qc2 调到 20 kN/m（其他荷载置 0），观察右柱顶出现的不平衡弯矩如何传到柱脚 —— 这是纯竖向荷载（H = 0）下的不对称侧移，与水平力侧移机制完全不同。
