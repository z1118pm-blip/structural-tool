一、基本假定与单元模型

  • 线弹性与小变形假定：本工具严格遵循线弹性理论。这意味着无论你施加多大的荷载，材料都不会屈服，杆件也不会发生大变形。工具中没有“极限承载力”的概念，所有结果都可以直接线性叠加。但这不代表可以无限制地输入大荷载，一旦超过现实中的比例极限，算出的内力就失去了工程意义。
  • 平面梁单元：每根杆件被离散为一个标准的 Euler-Bernoulli 梁单元，每个节点具有 3 个自由度（水平位移 u、竖向位移 v、转角 θ）。工具忽略剪切变形（即 Timoshenko 梁效应），因此对于跨高比极小的“深梁”，计算结果会存在一定误差。
  • “形常数”与“真实侧移”的差异（重点）：在手算位移法中，我们常背“形常数”表，认为单层单跨框架的柱子反弯点必然在 0.33h 处。但这有一个严苛的前提：两端节点无相对侧移。在矩阵位移法中（特别是默认开启“考虑轴向变形”时），梁受压会产生微小的轴向缩短，导致柱顶发生极其微小的侧移。这种极微小的侧移，在超静定结构中会通过刚度矩阵迅速放大，导致柱端弯矩比例不再严格是 4:2，反弯点随之偏离 0.33h。本工具不做近似，因此算出的反弯点会随侧移偏离理论假定。

二、半刚接节点的力学本质（核心）

在传统的结构力学中，节点要么是刚接（β=1），要么是铰接（β=0）。但在真实的钢框架或装配式混凝土结构中，节点往往处于半刚接状态。本工具通过引入端部柔度参数 α = (1-β) / (4β) 来修正梁单元的刚度矩阵。它的物理意义非常直观：

  • 当 βj = 1 时，α = 0，转动弹簧完全刚性，梁端弯矩可以完全传递给柱，这是标准的刚接框架；
  • 当 βj → 0 时，α → ∞，梁端的抗弯刚度被完全释放，退化为两端铰接。
  • 教材级理解：你可以把 β_j 想象成一个调节旋钮。从 1 调到 0 的过程，就是梁端从“死死焊住”逐渐变成“用一根有弹性的弹簧拉住”的过程。你会发现，随着 β_j 减小，梁端负弯矩急剧下降，而跨中正弯矩剧烈上升。

三、支撑（二力杆）的特殊处理

支撑是框架抵抗水平力的第二道防线。在模型底层，支撑单元被赋予了特殊的标记 kind:'brace'：

  • 纯轴力：局部刚度矩阵中，所有弯曲刚度项（如 12EI/L³）被强制清零，只保留轴向刚度 EA/L。
  • 两端铰接：支撑不参与 β_j 的修正，不论你把梁端刚度调到多少，支撑两端永远是理想铰接。
  • 仅受拉非线性：当开启“仅受拉”时，求解器会进入迭代。只要检测到支撑轴力出现压力（哪怕是极小的 10⁻⁴ kN），这根杆就会被直接“踢出”刚度矩阵，重新求解。这就模拟了真实工程中，长细比很大的柔性拉杆一旦受压就会屈曲失效退出工作的物理现象。

四、刚性楼板与自由度缩并

在现浇混凝土楼盖中，楼板的面内刚度极大。如果在水平力下，同一层的柱顶水平位移不一致，楼板会被撕裂。因此，本工具提供「刚性楼板」选项。在求解底层，程序采用了矩阵自由度缩并技术，强制让同层所有柱顶的水平位移相等。这就模拟了真实的刚性隔板效应，此时水平力会自动根据各柱的线刚度进行分配。

二、截面与刚度

  • 柱截面：bc × hc（出平面 × 平面内），Ic = bc·hc³/12，Ac = bc·hc。
  • 梁截面：bb × hb（水平 × 竖向），Ib = bb·hb³/12，Ab = bb·hb。
  • 中柱刚度比 r：中柱的 EI 与 EA 均为边柱的 r 倍。用于演示"柱刚度差异如何影响水平力分配"，界面保持简洁不展开为多组截面参数。
  • 截面按矩形实心计算，不考虑楼板共同工作、钢筋（纵筋与箍筋）等实际构造。

三、边界条件

柱脚（βf）

  • 平动（水平、竖向）始终约束。
  • 转动：βf = 1 时完全固定；βf = 0 时完全铰接；0 < βf < 1 时按弹性转动弹簧处理。
  • 弹簧刚度采用启发式公式 k_θ = (4EI_c/h₁)·β_f/(1−β_f)，使 βf 在 0.5 附近时弹簧刚度量级与柱自身转动刚度相近。它不是从节点平衡精确推导的弹簧刚度，只用于演示"从铰接到固定的连续过渡"。
  • 绘制柱脚符号：βf ≥ 0.99 画固定支座，βf ≤ 0.01 画铰接，中间画弹簧符号。

强迫位移与支座类型（每柱独立）

  • 可在「荷载」Tab 下对每根柱子独立设置 固接 / 铰接 / 滚轴 支座。
  • 竖向位移：正数表示沉降向下，负数表示基础上抬（如抗浮工况）。
  • 强迫转角：正数表示逆时针旋转，用于模拟基础不均匀沉降造成的柱底强迫扭转。为了便于视觉观察，程序在绘制静态简图时会自动将其放大为 30° 左右的直观倾角。

梁端（βj）

  • 通过修正梁单元局部刚度矩阵实现半刚接。
  • 采用标准半刚接梁单元模型，引入端部柔度参数 α = (1−β_j)/(4β_j)，对以下四项进行修正：
    项修正后
    横向刚度 kvv12EI/L3 · 1/(1+6α)
    耦合项 kvθ6EI/L2 · (1+2α)/(1+8α+12α2)
    转动自项 kθθ4EI/L · (1+3α)/(1+8α+12α2)
    转动互项 kθθ'2EI/L · 1/(1+8α+12α2)
    固端弯矩wL2/12 · (1+6α)/(1+8α+12α2)
  • βj = 1（α = 0）退化为标准刚接梁单元；βj = 0（α → ∞）退化为两端铰接。

四、荷载

  • 梁均布荷载 q₁、q₂、q₃：作用于跨内梁。支持「统一值」和「按跨指定」两种模式。在「按跨指定」模式下，可对不同跨赋予不同荷载，可轻松实现“荷载不利布置”的对比（如仅中跨加载、隔跨加载）。
  • 梁集中荷载 P₁、P₂、P₃：作用于跨内梁。默认在跨中，通过「按跨指定」可设置作用点距离左端的距离 a。求解器会在作用点处自动将梁单元拆分为两个子单元，从而在弯矩图上产生精确的“尖角”。
  • 悬挑均布荷载 qc1、qc2、qc3：作用于右侧各层悬挑梁，长度 Lc。悬挑梁为右柱节点伸出的标准刚接单元，不参与 βj 半刚接修正。
  • 水平力 H₁、H₂、H₃（仅正向，不支持反向）：两种施加方式
    • 无楼板：全部施加于左柱顶节点，模拟风压从左侧来。
    • 刚性楼板：强制同层柱顶水平位移相等，通过约束自动分配剪力，更接近真实现浇楼盖。
  • 非荷载作用 · 温度：全结构均匀升温 ΔT 会产生轴向膨胀受阻的次内力；结构内外温差（室外温度高于室内为正）仅作用于框架最外侧的边柱和顶层边梁，使结构产生向外膨胀的弯曲次内力。内部梁柱及悬挑梁截面本身无温差，不受此项影响。支撑默认不受温度影响。
  • 所有荷载为静力荷载，不考虑动力放大、偶然偏心、荷载组合系数。

五、支撑系统

支撑是「框架-支撑双轨制」的第二条抗侧力路径。与梁柱不同，支撑按「层 × 跨」网格逐格布置，每格独立配置形式、材质、截面与是否仅受拉。

布置形式

  • 在「模型」Tab 点击画笔（X / ╱ / ╲ / 无），再点击布置网格的格子即可涂抹；再次点击同一格且画笔相同则取消。
  • X 撑 = 同格两条对角线（╱ + ╲）各一根斜杆；╱ 或 ╲ = 单斜撑，只生成一根。
  • 支撑两端节点为该格左下 / 右下 / 左上 / 右上四个框架节点，杆长按实际几何 L = √(跨² + 层高²) 计算，倾角自动跟随跨度与层高变化。
  • X 撑同格的两根斜杆共用该格的材质、As 与「仅受拉」状态，但失效判定仍按单根各自进行。

材质与截面

  • 支撑材质独立于梁柱：钢 Q355（E = 2.06×10⁸ kN/m²）或混凝土 C30（E = 3.0×10⁷ kN/m²）。
  • 截面积 As 以 mm² 输入（默认 2000 mm²），内部换算为 m² 后计算轴向刚度 EAs。
  • 支撑只承担轴力，不区分强轴 / 弱轴。受压是否退出由「仅受拉」开关决定；另提供欧拉临界力粗估 Ncr = π²EA/λ²，λ = μL/i（μ=1，两端铰接），超限仅报警，不改变内力结果。

单元刚度

  • 支撑单元 kind:'brace'，局部刚度矩阵只保留轴向项 EA/L，所有弯曲刚度项（12EI/L³、6EI/L²、4EI/L、2EI/L）置 0。
  • 支撑两端强制铰接，不受 βj 滑块影响；内力图与荷载简图中无论 βj 设为多少，支撑两端都绘制铰接圆圈。
  • 支撑不参与梁端半刚接修正，也不参与柱脚 βf 弹簧。

仅受拉（逐格指定）

  • 每格支撑右上角有 T 角标：点击可单独开启 / 关闭该格「仅受拉」；「模型」Tab 的「全部仅受拉 / 全部普通」按钮为批量操作。
  • 求解器 analyzeTensionOnly 只对开启了「仅受拉」的支撑做失效判定：一旦检测到轴力受压（N < −1e−4 kN），即把该杆从 K 矩阵中移除、重新求解，最多迭代 15 次，直至不再有新的支撑失效。
  • 失效支撑的轴力按 0 输出，N 图上该杆不再显示数值；但杆件轮廓仍以灰色绘制，便于识别「曾经存在但已退出」的支撑。
  • 若某格 X 撑两根全部失效导致矩阵奇异，程序提示「仅受拉支撑全部退出（已失效 N 根），结构可能失稳」，而不是笼统的「刚度矩阵奇异」。
  • 普通支撑（未开启仅受拉）受压时照常工作，不受失效迭代影响。

绘图约定

  • 支撑仅绘制 N 图内力曲线；M / V 图下支撑不显示内力（弯曲刚度为零，M、V 恒为 0），但保留青色轮廓线以示支撑存在——这与 SAP2000 / MIDAS 等工程软件的处理一致，避免用户误以为"支撑消失了"。
  • 支撑轴力线强制使用青色 #22d3ee 绘制在最上层，并把显示比例强制放大 5 倍（refDiv 逻辑），避免被柱子的巨大轴力压得看不见。
  • 荷载简图中自动标注斜撑实际倾角（取整，如 34°）；X 撑两条线中点重合，已做去重与背景底色处理，防止文字重叠。

已知局限

  • 仅受拉采用「一次性受压失效 + 矩阵重算」的迭代法，未考虑支撑在反复荷载下的滞回性能（静力盲测够用，但不适用于动力时程或往复加载）。
  • 屈曲校核为欧拉临界力粗估（λ = μL/i，μ 固定 1.0），未考虑初始缺陷、真实稳定曲线、节点板约束；仅作量级参考，不是稳定验算。
  • X 撑两根共用一个格子的 As，不支持同一格内两根斜杆取不同截面。
  • 支撑与框架节点按理想铰接处理，未考虑节点板、螺栓群、节点域剪切变形。

六、梁系移除与穿层柱

「模型」Tab 新增了「梁系移除」网格，允许用户抽掉特定楼层的局部梁，用于模拟大堂、挑空区等造成的穿层柱工况。

  • 物理本质：点击网格上的梁将其移除后，该跨梁的单元将彻底从刚度矩阵中剔除，连带其自重和传递水平/竖向荷载的能力一并消失。
  • 交互联动：如果某一层的梁被全部移除，程序会自动禁用该层的水平力与竖向荷载输入滑块，防止将荷载施加在“真空”上。
  • 刚性楼板的陷阱：如果在移除梁的同时开启了「刚性楼板」，程序底层的自由度缩并依然会强制同层柱顶水平位移一致。这意味着未断开的楼板会起到“隔空传力”的作用，掩盖穿层柱真实的软弱性。若想观察纯框架的穿层效应，请务必切换到无楼板模式。

一、林同炎的线刚度比 ρ

在右侧实时读数面板中，我们提供了 ρ = (EIb / L) / (EIc / h)，即梁线刚度与柱线刚度的比值。这是判断框架受力特性的核心指标：

  • 强柱弱梁（ρ < 0.5）：柱的刚度远大于梁。此时框架的侧移主要是由柱的弯曲变形主导的，称为“弯曲型”。在地震下，塑性铰会优先生于梁端形成，形成良好的耗能机制。
  • 强梁弱柱（ρ > 2.0）：梁的刚度远大于柱。框架侧移呈现明显的“剪切型”（越往下层间位移越大）。这种体系非常危险，地震时柱端会先出现塑性铰，容易导致整体楼层垮塌。
  • 反弯点联动：打开反弯点小图，你会看到一个极其规整的力学现象：随着 ρ 的增大（梁越来越刚），柱子的反弯点会越来越接近跨中（即 x/h 趋向于 0.5）。因为超强的梁死死限制了柱子的转动，柱子的变形模式越来越接近“两端固接”的杆件。

二、P-Δ 二阶效应与失稳

传统一阶分析不考虑变形对内力产生的附加影响。但在高层或柔性框架中，竖向荷载 N 在发生侧移 Δ 后，会产生附加倾覆力矩 N·Δ。

  • 本工具没有采用复杂的几何非线性矩阵迭代，而是采用了一种工程上更直观的放大系数法：B = 1 / (1 - ΣN / ΣNcr)。
  • ΣN 是当前总竖向力，ΣNcr 是结构的弹性临界屈曲荷载。系统会自动剥离所有竖向荷载，单独施加一个纯水平力，反推出结构的真实侧向刚度，从而精准计算出 Ncr。
  • 教材级预警：当 ΣN / ΣNcr 接近 1 时（即 B 值急剧放大甚至变负数），意味着你的结构已经无限接近失稳（侧移突变）。此时现实中的结构早已发生大变形破坏，线弹性假定彻底失效。

三、为什么支座沉降会产生内力？

静定结构（如简支梁）的支座沉降不会产生任何内力，因为结构能自由变形。但本工具分析的是超静定刚架。当你拖动某根柱发生沉降时，由于多余的约束限制，结构无法自由变形，从而产生极大的附加内力。

  • 公式本质：K·ΔU = F_等效。沉降相当于在支座处强行塞入了一个强迫位移，这个位移通过刚度矩阵 K 耦合到了其他自由节点上，相当于施加了巨大的等效外力。
  • 经验法则：沉降产生的次内力大小，与支座的转动刚度（固接 vs 铰接）强相关。如果你把沉降柱脚设为“铰接”（β_f=0），你会发现沉降产生次内力会大幅减少。

四、求解方法（矩阵位移法）

  • 采用矩阵位移法（直接刚度法）：组装整体刚度矩阵 K，组装等效节点荷载向量 F，施加边界条件后高斯消元求解 K·U = F。
  • 高斯消元使用部分主元法；对角元 < 1e-14 时判定为奇异并提示。
  • 反力由 R = K_struct·U − F 计算（K_struct 不含弹簧贡献）。对于弹性柱脚，代码里从 K·U 中扣除弹簧力 kθ·θ 后得到弹簧反力矩。

二、内力符号约定

  • 轴力 N：拉为正，压为负。
  • 剪力 V：与单元局部坐标一致，V(x) = dM/dx = f₁ + w·x。
  • 弯矩 M：M(x) = −f₂ + f₁·x + w·x²/2。弯矩图绘于受拉侧。
  • 内力图正方向与单元局部坐标的 y 轴一致（柱竖向、梁横向）。

三、已知近似与局限

以下几点是模型的简化，使用时需注意。用于教学演示足够，但不能作为设计依据。
  1. βf 弹簧刚度为启发式，不是严格推导的弹簧刚度。主要用于演示从铰接到固定的趋势，不能与真实转动弹簧刚度值对应。
  2. βj 修正的梁单元是标准半刚接模型，但对多层多跨刚架，节点处柱的转动约束没有单独建模（即梁端的半刚接在节点处自动与柱刚接），这会影响含半刚接节点刚架的整体刚度。
  3. 水平力施加方式与楼板假设：
    • 无楼板（Hmode = 'none'）：同层各柱顶水平位移相互独立，水平力直接作用于左柱顶，依靠梁自身的轴向和弯曲刚度耦合传递。
    • 刚性楼板（Hmode = 'rigid'）：采用自由度缩并技术，强制同层各节点水平位移相等。水平力同样作用于左柱顶，由刚性约束自动按各柱侧移刚度分配。适用于现浇混凝土楼盖。
  4. 二阶效应为粗估：不做真正的 P-Δ 迭代（不组装几何刚度矩阵 Kg），仅用等效单自由度反推 B = 1/(1−ΣN/ΣNcr)，详见本节「五、P-Δ 放大系数与侧移刚度的说明」。
  5. 多跨对称结构的浮点虚假侧移：单跨无悬挑纯竖向荷载已在求解前用约束消除奇异；多跨对称结构（等跨、等层高、r=1、荷载对称）理论上水平位移为零，但代码未做此约束，浮点噪声可能产生极小侧移。对侧移刚度大的结构影响可忽略；对全铰接或半刚接的柔性框架，可能出现可见的虚假侧移。
  6. 无节点域：节点处按纯刚接或纯铰接处理，未考虑节点域剪切变形。
  7. 悬挑梁简化：悬挑梁按标准刚接单元处理，不参与 βj 半刚接修正；悬挑端为自由端，未建模实际边梁的弹性约束。
  8. 两端完全铰接的梁：当 βj 降至 0 时，梁单元弯曲刚度归零，仅保留轴向刚度（类似链杆）。因此多跨连续梁若中间跨两端完全铰接，无法传递剪力，结构侧向柔度会显著增大。这是标准有限元处理方式，并非程序错误。
  9. 刚性楼板与梁系解耦：在刚性楼板假设下，只要楼板存在，即使梁被抽空，水平力依然能通过虚拟的刚性隔板在柱间传递。这是为了模拟无梁楼盖或局部抽梁但现浇板完好的真实受力状态，并非计算错误。
  10. 支撑仅受拉的非线性：采用「一次性受压失效 + 矩阵重算」的迭代法（最多 15 次）。一旦检测到某根仅受拉支撑轴力受压（< −1e−4 kN），即将其标记为失效、从 K 矩阵中移除并重新求解，直至不再有新的支撑失效。若某格 X 撑两根全部失效导致矩阵奇异，程序会提示「仅受拉支撑全部退出，结构可能失稳」。该法未考虑支撑在反复荷载下的滞回性能，仅适用于静力单向加载的概念演示，不适用于动力时程或往复荷载分析。逐格指定「仅受拉」仅影响该格支撑，普通支撑受压时仍正常工作。
  11. 每根杆件一个单元：对于只有均布荷载的情况已足够精确，但对有多个集中力或复杂荷载的杆件精度有限。
  12. 无剪切变形：按 Euler-Bernoulli 梁理论，忽略 Timoshenko 梁的剪切效应。
  13. 无材料非线性：不考虑混凝土开裂、钢筋屈服等实际非线性效应。
  14. 线弹性范围：计算结果可用于叠加，但不适用于承载能力极限状态验算。
  15. 规范背景：默认采用中国现行规范体系（GB 50010、GB 50011 等），但不做规范校核，仅作为量级参考。

四、支座沉降与强迫位移

在「荷载」Tab 的「支座类型与强迫位移」组中，可对每根柱独立指定竖向位移或强迫转角。

  • 竖向沉降/上抬：沉降会引起超静定结构内部产生附加内力（类似于拉压杆效应）。输入负值（如 -50mm）可模拟抗浮工况下基础上抬。
  • 强迫转角（局部不均匀沉降）：模拟基础转动造成的柱底强迫转角。这会在柱底产生极大的约束弯矩，并带动上部框架发生侧移和内力重分布。
  • 与冻结对比：先关闭强迫位移、点击「冻结」保存基线，再拖动强迫位移滑块，变形图与内力图会以浅灰虚线（基线）与实线（当前）对比，前后差异一目了然。
  • 局限：不支持多柱之间的沉降差相互作用（分别单独输入），未考虑土体固结时间效应。

五、P-Δ 放大系数与侧移刚度的说明

P-Δ 放大系数 B（仅在「荷载」Tab 开启 P-Δ 开关后显示）：

  • 物理含义：二阶效应会把当前的内力和位移放大约 B 倍。B = 1 表示无二阶效应；B = 1.1 表示放大 10%。
  • 计算式：B = 1 / (1 − ΣN / ΣN_cr)，其中 ΣN 是当前工况下的柱脚竖向反力之和。
  • 精准的 N_cr 推导：为避免悬挑或不对称竖向荷载产生的“假侧移”污染刚度，程序在后台会自动构建一个“纯水平力工况”，单独求得真实的纯侧向刚度，进而反推出准确的等效弹性临界荷载 ΣN_cr。
  • ΣN / ΣN_cr 是稳定系数，必须 < 1；越接近 1，B 越大，越接近失稳。
  • ⚠ 局限：虽然 N_cr 已剥离了竖向荷载干扰，但本工具依然采用等效单自由度公式反推（N_cr ≈ ΣH·h/|u顶,max|），且为一次性线弹性求解，未做真正的几何非线性矩阵迭代。对刚度沿高度极不均匀的结构，B 值误差可能超过 20%；接近失稳（ΣN/ΣN_cr 接近 1）时误差更大。面板显示仅作量级参考，不能用于实际工程的稳定验算。

侧移刚度 K：

  • 定义：K = ΣH / |u_顶平均|，即总水平力除以顶层柱顶的平均水平位移。
  • ⚠ 当竖向荷载不对称时（例如有悬挑均布 qc，或左右跨荷载不等），柱顶位移里会混入竖向荷载引起的侧移分量，此时面板上显示的 K 是一个表观值，会比纯侧移刚度偏小。
  • 如果想要严格的侧移刚度：把悬挑荷载和跨内荷载全部调 0，只保留水平力。
  • 自检场景下，K 的变化趋势（拖动 βf、r 时 K 怎么变）比绝对值更有意义。

一、后处理面板的高阶解读

1. 截面探针（应力分析）
在内力图上点击任意杆件，右侧会弹出截面应力图。这是基于经典的平截面假定，利用轴力 N 和弯矩 M 计算得出的：σ = N/A ± M/W。
当你看到红色的部分（受压）和蓝色的部分（受拉）是不对称的，说明该截面处于大偏心受力状态（弯矩主导）；如果两边颜色对称但只有一种颜色（全红或全蓝），说明处于小偏心受力状态（轴力主导）。利用这个探针，你可以直观地看到“框架作用”是如何在中柱中产生巨大轴力的。

2. 刚度贡献分解（K值对比）
这个面板用于回答“到底是什么在抵抗水平力？”。程序会在后台进行一次“剥离计算”：比如求 `去支撑后 K` 时，程序会在内存中暂时删掉所有支撑，重新计算一次顶层位移，从而得到去支撑后的刚度。
易错点：下降百分比并不能线性相加。比如去掉支撑刚度下降 50%，去掉梁约束刚度下降 40%，你绝对不能得出结论“支撑占 50%，梁占 40%”。它们互相之间是高度耦合的。你需要关注的是哪一项剥离后，结构的侧移发生了急剧的失稳性增加。

3. 受压支撑校核
欧拉临界力 Ncr = π2EA / λ2（其中 λ = μL / i）。在真实的工程中，如果一根支撑的长细比 λ 过大，它在远没达到屈服强度前，就会发生横向屈曲（受压失稳）。当你在扫掠工况中使得某根支撑内力超过 Ncr 时，面板会亮起红灯并报警。虽然工具为了保持线弹性假定不会让这根杆直接断裂，但这提示你：如果你真的开启“仅受拉”开关，这根杆早就退出了。

二、关于界面与操作的说明

  • 左侧控制栏：包含「自检」/「模型」/「荷载」三个 Tab。其中「自检」内置了 30+ 个预设工况（分 A~G 七个大类）。「模型」用于配置几何与截面，「荷载」用于配置受力条件。支持快捷键 1 / 2 / 3 快速切换。
  • 右侧读数面板：实时显示截面参数、刚度比、逐层逐跨 ρ 等。其中「体系判定」模块会根据当前的梁柱线刚度比 ρ 与梁端刚度 β_j，自动判定当前的结构体系（如：强柱弱梁、典型刚接框架、铰接排架等）。
  • 内力图工具条：M / N / V / R 切换内力类型；冻结 把当前结果存为浅灰虚线基准；📷 导出当前内力图为 PNG。底栏「缩放」滑块只影响显示比例，不改变计算结果。
  • 参数扫掠（底栏「▶ 扫掠」）：单参数默认 3s 循环播放（自检卡片为 12s 慢速播放）。录制功能可录制为视频（自动选 mp4 / webm）。
  • 底部状态栏：RESIDUAL 显示相对平衡残差（越小越准）。STATUS 相对残差 < 1e-8 显示绿色 OK；仅受拉迭代 15 次未收敛时显示 NC·未收敛。

二、力学概念自检建议

左侧栏「自检」Tab 内置了 20+ 个一键播放的力学场景。场景按大类折叠（A~G），点击卡片即可自动加载工况、开启扫掠并慢速播放；部分概念类卡片（如不利布置）为静态对比，点击后会弹出提示。

A. 弯矩与刚度

  1. 梁端弯矩释放：扫掠梁端 βj (0→1)，看梁端弯矩逐渐产生、跨中正弯矩随之减小。
  2. 柱脚弯矩释放：扫掠柱脚 βf (0→1)，看柱脚弯矩逐渐产生、底层侧移随之减小。
  3. 梁刚度与反弯点：扫掠梁高 hb，看梁刚度变大如何使柱反弯点下移。
  4. 柱截面三次方效应：扫掠柱高 hc (300→800)，看侧移随 hc 增大急剧减小（Ic ∝ hc³）。
  5. 形常数的陷阱（轴向变形）：单层单跨 · 强柱弱梁。形常数推导反弯点为 0.33h，但建立在无侧移假定上。切换“忽略轴向变形”与“考虑轴向变形”，观察微小侧移如何导致反弯点在 0.33h 与 0.30h 之间跳变。
  6. 悬挑长度平方效应：扫掠悬挑长度 Lc，看均布荷载下根部弯矩的平方级增长（M ∝ Lc²），以及端部挠度的四次方级剧增（Δ ∝ Lc⁴）。
  7. 跨中与支座弯矩：扫掠均布荷载 q1 (0→100)，观察跨中正弯矩与支座负弯矩线性增长。
  8. 集中力弯矩尖角：单层单跨 · 跨中集中力。扫掠 P1，观察集中力作用点处弯矩图的“尖角”。
  9. 反弯点 vs ρ 联动：两层两跨 · 纯水平力。扫掠梁高 hb，看反弯点小图中，随着梁柱线刚度比 ρ 的增加，反弯点如何向 x/h=0.5 靠拢（可拖出悬浮窗看）。
  10. 柱刚度对梁反弯点的影响：单层单跨 · 竖向均布荷载。扫掠边柱高 hc (300→800)。柱越细，对梁端约束越弱（趋近铰接），梁反弯点靠近支座；柱越粗，约束越强（趋近固接），反弯点向跨中移动。
  11. 水平力下的反弯点偏移：单层单跨 · 纯水平力。扫掠梁高 hb，验证反弯点精确解 y/h = (1+3k)/(1+6k)。观察梁越刚，反弯点如何从 0.6h 以上回落到 0.5h。

B. 轴力与框架

  1. 框架作用传递：扫掠梁端 βj (0→1)，看中柱轴力如何随梁约束的增强而增大。
  2. 悬挑偏心拉力：扫掠悬挑荷载 qc1 (0→100)，看悬挑倾覆力矩导致的柱拉力。
  3. 柱脚刚度与倾覆力矩：单层单跨 · 纯水平力。扫掠柱脚 βf (0→1)，验证 M倾覆 = M柱脚 + N×L。铰接时柱脚弯矩为0，柱轴力极大；刚接时弯矩被柱脚分担，轴力减小。

C. 变形与侧移

  1. 层刚度变化与变形集中：扫掠二层层高 h2 (2.5→7)，看层高增大使二层线刚度降低时，层间位移角如何向该层集中。
  2. 不对称侧移：扫掠左跨长 L1 (3→12)，看单侧竖向荷载偏心引起的框架侧移。
  3. 悬挑重力侧移：扫掠悬挑荷载 qc1，看纯重力偏心侧移（放大显示）。

D. 水平力与二阶

  1. 刚性楼板内柱分配：扫掠内柱刚度比 r (0.25→4)，看内柱刚度变大时，如何通过楼板自动分走更多剪力。
  2. 刚性楼板梁约束影响：扫掠梁端转动 βj (0→1)，看梁的转动约束如何减小整体侧移，并使柱反弯点向跨中移动。
  3. P-Δ 二阶效应：扫掠均布荷载 q1，看竖向荷载如何使 B 值急剧放大并逼近失稳。
  4. P-Δ 层高敏感性：扫掠层高 h1，看层高增加时 Ncr 平方级下降，导致 B 值急剧放大。
  5. P-δ 与 P-Δ 的区别：静态概念卡，展示整体侧移（P-Δ，本工具计算）与构件自身挠曲（P-δ，本工具不计算）的力学差异。
  6. 穿层柱模拟：两层两跨 · 无楼板。移除底层左跨梁形成悬空柱，观察顶部水平力下左柱夸张的弯曲变形，以及因失去侧向约束导致的刚度体系突变。

E. 支撑系统

  1. 支撑截面积与侧向刚度：扫掠 As (100→5000)，看支撑变粗后侧移显著减小、轴力增大、柱端弯矩被分走。
  2. 仅受拉支撑的单向工作：扫掠 H₁，N 图上始终只有受拉斜杆有数值，受压杆自动退出。
  3. 支撑角度与轴力分配：扫掠 L₁ (3→12)，倾角变小使斜杆轴力减小；在截面积不变的纯线弹性假定下，整体侧向刚度的理论极值在 θ ≈ 35.3°（L₁ ≈ 5.7m），而非直觉上的 45°。

F. 非荷载作用

  1. 支座沉降的附加内力：扫掠左柱沉降 (0→100mm)，看超静定结构在"什么都没加"的情况下 M 图从零逐渐出现、反力重新分配、结构整体倾斜。
  2. 支座上移（抗浮）：扫掠左柱竖向位移 (0→-100mm)，模拟地下水浮力导致的基础上抬。观察框架整体上拱以及梁柱内力的反向重分布。
  3. 基础强迫扭转：扫掠柱底强迫转角 (0°→30°)，模拟基础局部不均匀沉降产生的强制扭动。观察柱底巨大的抗弯弯矩以及框架被强行带偏的侧移。
  4. 均匀升温的轴力：扫掠整体温升 ΔT，看超静定框架因膨胀受阻产生的内部轴力重分布。
  5. 单侧温差的反弯点：扫掠截面内外温差 ΔT，看梁柱因温度梯度产生弯曲及对应的反弯点变化。
